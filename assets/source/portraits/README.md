# Ash Ledger Character Direction

## Asset

`ash-ledger-character-direction-v0.120.png`

Generated for this project as an original visual-direction sheet, then selected as the source for the deterministic Commander X16 portrait pipeline.

## Final prompt

Create a clean, text-free character portrait concept sheet for a premium 16-bit-era Protocol Seven RPG. Show five distinct, evenly spaced head-and-shoulders panels: Mara Venn, composed female field operator; Eli Mercer, observant male infiltrator; Nia Okafor, brilliant Black female interpreter-scientist; Miriam Quill, practical 1906 architectural drafter with a blue pencil behind her right ear and ash on her gray coat; and Silas Venn, morally serious Covenant operative in a dark 1906 work coat. Use original character designs, crisp pixel-art-inspired forms, expressive readable silhouettes, copper firelight, signal-cyan rim light, ash gray, blue-pencil blue, black, and dark red. Clothing must plausibly pass in 1906. Avoid text, logos, watermarks, modern tactical armor, steampunk goggles, chibi proportions, exaggerated anime features, glossy mobile-game rendering, photorealism, and imitation of an existing commercial game.

## Production rule

This direction sheet is not loaded directly by the game. `tools/build_portraits.py` crops, resizes, quantizes, previews, and packs the approved panels into the runtime C data.
