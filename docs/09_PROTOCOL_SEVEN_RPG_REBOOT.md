# Protocol Seven: The Ash Ledger — Commander X16 RPG

## Product identity

This project is a story-driven, SNES-style roleplaying game for Commander X16. It adapts the Protocol Seven universe and begins with Adventure Path 01, Mission 01: *The Ash Ledger*.

The earlier Amber Wilds software remains valuable as a hardware and workflow prototype. It is not story canon for this game.

## Creative authority

1. Current Protocol Seven canonical rules source and active playtest locks
2. Current *Continuance Files* Campaign Director Guide
3. Current *Ash Ledger* GM Field Guide and Player Briefing
4. This video-game adaptation document
5. Current implementation and tests

The video game may compress table procedures into readable interactive scenes, but it must not silently redefine a frozen Protocol Seven mechanic.

## Experience target

- expressive top-down exploration;
- portrait-driven conversations;
- a recurring party of Vectors;
- tactical, menu-driven Protocol Dice combat;
- investigation choices that change Carrier and Exposure;
- cinematic chapter openings and verification sequences;
- recognizable historical texture without treating disaster as spectacle;
- secrets, optional rescues, and remembered-history callbacks.

## Core loop

Briefing → insertion → establish cover → investigate → identify leverage → intervene → establish Carrier → contain Exposure → extract → Historical Verification.

## Presentation grammar

- 40×30 display for readable text and strong tile silhouettes;
- hardware sprites for party actors and important animated objects;
- restrained copper, ash, blue-pencil, signal-cyan, and Protocol-red palette;
- dialogue boxes preserve the visible scene whenever possible;
- character names, portraits, and short lines replace long exposition;
- dedicated battle composition with visible dice, AP, HP, and stakes;
- version and build identity displayed on the title and developer screen.

## Vertical-slice boundary

v0.100 covers a compressed opening chapter: briefing, insertion, rescue, two investigation routes, meeting Miriam Quill, confronting Silas Venn, establishing the Carrier, extraction, and Historical Verification.

It is a proof of the finished game’s narrative and mechanical structure, not a claim that the complete tabletop mission is already adapted.
