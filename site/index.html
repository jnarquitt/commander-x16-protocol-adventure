Quick launch

Run it in the official emulator

  1. Download a matching Commander X16 emulator and rom.bin.
  2. Download PROTOCOL.PRG using the button above.
  3. Open a terminal in the emulator folder and run:
./x16emu -prg /path/to/PROTOCOL.PRG -run

On Windows, use x16emu.exe. You can also copy the PRG to an SD card and load it on Commander X16 hardware.
